   Пояснение к заданию к 1 лабе:
В общем есть файл, в нём поле из решёток `#` и точек `.`.
Пользователь вводит координаты X и Y.
если попал в решётку - меняем её на звёздочку `*`.
если попал в точку - ничего не делаем.

Как я к этому пришёл:

1. Как читать поле из файла?
   Поле - просто набор строк. Использую `File.ReadAllLines`,
   получаю массив строк, где каждая строка — это ряд поля.

2. Как понять, куда попал пользователь?
   X - номер символа в строке (столбец),
   Y - номер строки (ряд).
   Значит, нужная клетка — это `field[y][x]`.

3. Что если пользователь введёт не то?
   - буквы вместо цифр → проверяю через `int.TryParse`.
   - координаты больше поля → проверяю границы.
   Без этих проверок программа падала бы с ошибкой.

4. Как заменить символ?
   В C# строки нельзя менять напрямую.
   Поэтому превращаю строку в массив символов (`ToCharArray`),
   меняю нужный символ, потом собираю обратно (`new string(row)`).

5. Где лежит файл?
   Файл `field.txt` ищу на рабочем столе.
   Путь получаю через `Environment.GetFolderPath(Environment.SpecialFolder.Desktop)`.
   Если файла нет — создаю его с примером поля.

6. Как сохранить изменения?
   После замены сохраняю поле обратно в файл через `File.WriteAllLines`.
   Так при следующем запуске изменения уже будут на месте.
